## One stable folder per purpose (2026-10-12)

The owner rejects the proliferation of subfolders for experiments and asks for
a single folder per purpose. Reuse stable domain/purpose locations instead of
creating a new trial tree for each attempt. Preserve iterations with clearly
named files and evidence manifests inside those locations.

Permanent port features, including settings and rendering enhancements, belong
in tracked port source, not indefinitely in ignored prototype folders. Private
game inputs, generated builds, captures and analysis remain ignored and are
kept in their stable purpose locations.

This records the organization rule. No existing directories were moved or
deleted: current launchers and cached build inputs still depend on their paths.
Consolidation must preserve original inputs/evidence and update those references
before removing obsolete directory trees.
