## Port: the library tables name five functions as the build does (2026-10-12)

- What was seen: a PC program built from main `f10e92ba` with `port/tools/hostbuild.py --psyz` refused at start with `refused: library: func_8015764c (kernel) is listed but this build has no library function of that name without C`.
- Cause: on 2026-10-11 the build table gave names to five library functions when their units became exact: `SetRCnt` and `StartRCnt` (commit `4db97ddf`), `ResetRCnt` (`572c7fbc`), `PutDispEnv` and `SetDrawEnv` (`fb949635`, batch 13). The port's tables kept the address names `func_8015764c`, `func_80157720`, `func_80157784` (`port/src/kernel.c`) and `func_80158470`, `func_80158a84` (`port/src/gpu.c`). The start check of `port/src/library.c` looks a listed name up among the build's library functions without C, by name. No PC build was made for those batches (the rule for exact units), so nothing showed it.
- Change: the five names in the two tables; the same two graphics names in `port/tools/test_hostgpu.py` (its expected list of served routines and its lookups) and in `port/tools/ui_layout_gpu_test.c`; one comment in `port/tools/test_hostlaunch.py`.
- What ran on this change: `hostbuild.py --config ps1/src/build.toml --psyz` (a PsyZ build made with this head's `port/psyz.patch`): `units: 3982 compiled, 0 of them nonmatching, 0 failed`, linked and verified. `sfa2.exe --list-library` on that program: status 0, the five functions listed under their names, last line `library: 85 host routines, 133 left that stop`; on the program built from `f10e92ba` the same command printed the refusal above. `test_hostkernel_start.py`: `all 1 cases behaved as required`. `test_hostlaunch.py`: `all cases behaved as required`. `test_hostgpu.py` (offscreen): `all cases behaved as required`. `test_ui_layout.py`: `OK`.
- Not run: the game itself (no start of the program on a disc by this lane), the other suites of the review plan (audio, the I/O page, mirror, modules, pads, video), which do not read these names.
- For the lanes: a unit that gives a library function a name changes the name the port's tables must use. `git grep -n '"func_80[0-9a-f]*"' -- port/src` lists the address names still in the tables; `sfa2.exe --list-library` on a fresh build is the check.
